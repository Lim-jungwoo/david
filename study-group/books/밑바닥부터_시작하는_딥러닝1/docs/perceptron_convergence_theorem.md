# 기본 퍼셉트론 판별식

퍼셉트론은 입력 벡터 `x`와 가중치 벡터 `w`의 내적(dot product)을 계산한 뒤,  
그 부호를 이용해 분류한다.

$$
\hat{y} = \text{sign}(w^\top x)
$$

- $\hat{y}$ : 퍼셉트론의 출력(예측 레이블)
- $w^\top x$ : 가중치 벡터와 입력 벡터의 내적
- $\text{sign}$ 함수 :
  - 값이 0보다 크면 +1
  - 값이 0보다 작으면 -1

---

## 1. $w^\top x$의 의미

- $w$: 가중치 벡터 (열 벡터, column vector)
- $x$: 입력 벡터 (열 벡터, column vector)
- $w^\top$: $w$를 전치(transpose)한 행 벡터 (row vector)
- $w^\top x$: 행 벡터와 열 벡터의 곱 → 내적(dot product)

즉,

$$
w^\top x = \sum_{i=1}^n w_i x_i
$$

이는 **가중치와 입력을 원소별로 곱한 뒤 모두 더한 값**이다.

---

## 2. 판별 방법

- $\hat{y} = +1$, if $w^\top x > 0$
- $\hat{y} = -1$, if $w^\top x < 0$

이 값의 부호(sign)에 따라 퍼셉트론은 입력을 어느 클래스에 속할지 결정한다.

## 올바른 분류 조건

퍼셉트론의 예측이 정답과 일치하려면, 정답 레이블 `y`와 내적 값 `wᵀx`의 부호가 같아야 한다.

$$
y \,(w^\top x) > 0
$$

- $y = +1$ → $w^\top x > 0$ 이어야 함
- $y = -1$ → $w^\top x < 0$ 이어야 함

---

## 오분류 조건

퍼셉트론이 잘못 분류했을 때는 정답과 내적 값의 부호가 다르거나, 경계 위에 위치한다.

$$
y \,(w^\top x) \le 0
$$

- $y = +1$인데 $w^\top x \le 0$ → 양수를 음수로 잘못 분류
- $y = -1$인데 $w^\top x \ge 0$ → 음수를 양수로 잘못 분류

# 퍼셉트론 수렴 정리 (Perceptron Convergence Theorem)

## 1. 정의

퍼셉트론 수렴 정리는 데이터셋이 선형적으로 구분(linearly separable) 가능하다면
퍼셉트론 학습 알고리즘이 유한 번의 가중치 업데이트 후 반드시 수렴한다는 정리이다.
즉, 잘못 분류되는 데이터가 더 이상 없어지는 순간이 존재한다.

---

## 2. 퍼셉트론 구성 요소

- 입력 벡터: x
- 레이블: y ∈ {+1, −1}
- 가중치 벡터: w
- 편향(bias)은 x에 상수 1을 추가한 확장 입력으로 흡수 가능

---

## 3. 학습(업데이트) 규칙

퍼셉트론은 잘못 분류된 샘플에 대해서만 가중치를 갱신한다.

$$ w \leftarrow w + y \, x $$

- 오분류 조건: $y (w^\top x) \le 0$ 인 경우 갱신 수행
- 올바르게 분류되면 갱신하지 않음

---

## 4. 정리의 조건

- 데이터셋이 선형적으로 구분 가능해야 한다.
- 즉, 어떤 참 가중치 w* 가 존재하여 모든 샘플 i에 대해 $y_i ((w^*)^\top x_i) > 0$ 이다.

---

## 5. 정리의 의미

- 수렴 보장: 위 조건이면 퍼셉트론은 유한 번의 업데이트 후 더 이상 변화하지 않는다.
- 한계: 선형 분리가 불가능하면(XOR 등) 수렴하지 않고 반복된다.
- 함의: 비선형 분리를 위해 은닉층을 둔 다층 퍼셉트론(MLP)이 필요하다.

---

## 6. 직관적 설명

- 한 직선(또는 초평면)으로 두 클래스를 완전히 나눌 수 있다면, 퍼셉트론은 결국 그 경계를 찾는다.
- 직선으로 나눌 수 없다면 계속 경계를 바꾸며 방황한다.

---

## 7. 요약

- 정리: 선형 분리 가능 → 퍼셉트론은 유한 번 내 수렴.
- 한계: 선형 분리 불가 → 수렴 보장 없음.
